IRIS DATASET¶

This project uses the classic Iris dataset to demonstrate unsupervised machine learning using the K-means clustering algorithm. The objective is to group Iris flower samples into clusters based on their physical attributes, such as sepal length, sepal width, petal length, and petal width and evaluate whether the algorithm can separate the different species based on their similarities.

Rule Based Classification¶

Since the data set was observed to be almost perfectly separated when looking at the daata, it was decided to try to do it manually to later compare it to a ML model. After all the best way to do things will always be the simplest.

K - Means Clustering Model¶

Now it is time to use the KMeans clustering model. First, the data needs to be scaled because K-Means clustering calculates distances between data points. Features with larger numerical ranges can have a greater influence on the distance calculations and dominate the clustering process.

In [263]:
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
x_train_scaled = scaler.fit_transform(x_train)

After scaling the data, the K-Means clustering algorithm can be applied. However, K-Means requires the number of clusters to be specified. Since the Iris dataset contains three known species, we could directly select three clusters for this analysis.

In another ocassion, the number of clusters is usually not known. In that case, the elbow method can be used to estimate them. The elbow curve evaluates the model's inertia for different values of "k".

In [264]:
inertia = []

for k in range(1, 11):
    kmeans = KMeans(n_clusters=k, random_state=1)
    kmeans.fit(x_train_scaled)
    inertia.append(kmeans.inertia_)

plt.plot(range(1, 11), inertia, marker='o')
plt.xlabel("Number of Clusters (k)")
plt.ylabel("Inertia")
plt.title("Elbow Curve")
plt.show()

Now that the elbow curve indicates that the optimal number of clusters is approximately k = 3, this value will be used for the K-Means model.

Initially, the model will be trained using all the features: sepal length, sepal width, petal length, and petal width. This will provide a baseline for evaluating the model.

Conclusion¶

The K-Means algorithm was able to identify meaningful patterns in the Iris dataset. The results showed that petal measurements provide stronger separation between species than sepal measurements. Using only petal length and petal width increased the performance (Adjusted Rand Index) from 0.430 to 0.872, demonstrating that feature selection plays an important role and that some of the features were causing more noise.

However, the rule based approach achieved higher accuracy of 0.946 because it was specifically designed around the observed separation between petal length and species. K-Means on the other hand, was able to approximate these groups without any prior information about the classes.
